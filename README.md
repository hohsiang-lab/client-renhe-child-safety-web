# client-renhe-child-safety-web

D008 — 仁和社區兒少防暴宣導互動網站

## Tech Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- React Router v7
- Framer Motion

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Project Structure

```
src/
├── components/        # 共用元件
├── pages/             # 頁面元件
├── assets/
│   ├── images/        # AI 生成圖片
│   ├── audio/         # 語音 MP3
│   └── svg/           # SVG 互動圖
├── data/              # 題目資料
└── hooks/             # 自訂 hooks
```
